PharmaXpert is an Android application designed to streamline pharmacy and medical shop operations. Built using Java, XML, and Firebase, it enhances efficiency, improves communication, and ensures better service delivery.

Features

User Authentication: Secure login and profile management for admins and users.

Product Management: Admins can add, update, and delete products; users can browse products.

Order Management: Users can place orders, track status; admins can manage and process orders.

Real-Time Data Sync: Firebase integration ensures real-time updates for inventory and orders.

Reports & Insights: Track sales, inventory, and user activity.

Technology Stack

Frontend: Java, XML (Android UI)

Backend: Firebase (Authentication, Firestore, Realtime Database, Storage)

Version Control: Git

System Requirements

Development:

Processor: Intel Core i5 or better

RAM: 8GB (minimum), 16GB (recommended)

Storage: SSD with 100GB (minimum)

Mobile Devices (End Users):

Processor: ARM-based processors

RAM: 2GB (minimum), 4GB (recommended)

Storage: 100MB (minimum) for app, additional for data

Network: Stable internet for Firebase connectivity

Modules

Profile Module: Admin (login & profile updates), User (registration, login, profile updates)

Product Module: Admin (add/delete products), User (view products)

Order Module: Admin (manage & cancel orders), User (place orders, track status)

Security & Testing

Firebase Authentication for secure access

Data validation and real-time security rules in Firestore

Unit and integration testing to ensure app stability
